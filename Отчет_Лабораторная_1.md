# Задание 1. Методы

## Задача 1. Дробная часть
### Текст задачи
Дана сигнатура метода: `public double fraction(double x);`  
Нужно вернуть только дробную часть числа x.  
Пример: x = 5.25 → 0.25

### Алгоритм решения
Целую часть отбрасываю через приведение к int, потом вычитаю из исходного числа.

```java
public double fraction(double x) {
    int c = (int) x;
    return x - c;
}
```

## Задача 2. Сумма знаков
### Текст задачи
Дана сигнатура метода: `public int sumLastNums(int x);`  
Сумма двух последних цифр.  
Пример: x = 4568 → 14

### Алгоритм решения
Если число отрицательное — делаю положительным. Последнюю цифру беру через %, предпоследнюю через /10 и снова %.

```java
public int sumLastNums(int x) {
    if (x < 0) x = -x;
    int a = x % 10;
    int b = (x / 10) % 10;
    return a + b;
}
```

## Задача 3. Тридцать пять
### Текст задачи
Дана сигнатура метода: `public boolean is35(int x);`  
true, если число делится на 3 или на 5, но не на оба сразу.

### Алгоритм решения
Смотрю остатки от деления на 3 и на 5. Если оба true — false, если хотя бы один — true.

```java
public boolean is35(int x) {
    boolean a = x % 3 == 0;
    boolean b = x % 5 == 0;
    if (a && b) return false;
    if (a || b) return true;
    return false;
}
```

# Задание 3. Циклы

## Задача 1. Числа подряд
### Текст задачи
Дана сигнатура метода: `public String listNums(int x);`  
Строка с числами от 0 до x через пробел.

### Алгоритм решения
Цикл от 0 до x, собираю строку.

```java
public String listNums(int x) {
    String s = "";
    for (int i = 0; i <= x; i++) {
        if (i == 0) s = "" + i;
        else s = s + " " + i;
    }
    return s;
}
```

```java
public String reverseListNums(int x) {
```

### Алгоритм решения
Начинаю с 1 и y раз умножаю на x.

```java

    int r = 1;

    }
    return r;
}
```

## Задача 5. Длина числа
### Текст задачи
Дана сигнатура метода: `public int numLen(long x);`  
Сколько цифр в числе.

### Алгоритм решения
Если 0 — сразу 1. Иначе делю на 10 в цикле, пока не станет 0, считаю шаги.

```java
public int numLen(long x) {
    if (x == 0) return 1;
    if (x < 0) x = -x;
    int n = 0;
    while (x > 0) {
        x = x / 10;
        n++;
    }
    return n;
}
```

# Задание 4. Массивы

## Задача 1. Поиск первого значения
### Текст задачи
Дана сигнатура метода: `public int findFirst(int[] arr, int x);`  
Индекс первого вхождения x, или -1 если нет.

### Алгоритм решения
Обычный проход с начала. Как только нашёл — возвращаю индекс.

```java
public int findFirst(int[] arr, int x) {
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] == x) return i;
    }
    return -1;
}
```

## Задача 3. Поиск максимального по модулю
### Текст задачи
Дана сигнатура метода: `public int maxAbs(int[] arr);`  
Элемент с самым большим модулем (сам элемент, а не модуль).

### Алгоритм решения
Использую свой abs. Храню и значение, и его модуль, обновляю когда нахожу больше.

```java
public int maxAbs(int[] arr) {
    int maxV = arr[0];
    int maxM = abs(arr[0]);
    for (int i = 1; i < arr.length; i++) {
        int m = abs(arr[i]);
        if (m > maxM) {
            maxM = m;
            maxV = arr[i];
        }
    }
    return maxV;
}
```

## Задача 4. Добавление в массив
### Текст задачи
Дана сигнатура метода: `public int[] add(int[] arr, int x, int pos);`  
Вставляет число x на позицию pos, возвращает новый массив.

### Алгоритм решения
Создаю массив на 1 больше. Копирую до pos, вставляю x, копирую остальное со сдвигом.

```java
public int[] add(int[] arr, int x, int pos) {
    int[] r = new int[arr.length + 1];
    for (int i = 0; i < pos; i++) r[i] = arr[i];
    r[pos] = x;
    for (int i = pos; i < arr.length; i++) r[i + 1] = arr[i];
    return r;
}
```

## Задача 5. Добавление массива в массив
### Текст задачи
Дана сигнатура метода: `public int[] add(int[] arr, int[] ins, int pos);`  
Вставляет весь массив ins начиная с позиции pos.

### Алгоритм решения
Почти то же, только вместо одного числа копирую весь ins.

```java
public int[] add(int[] arr, int[] ins, int pos) {
    int[] r = new int[arr.length + ins.length];
    for (int i = 0; i < pos; i++) r[i] = arr[i];
    for (int i = 0; i < ins.length; i++) r[pos + i] = ins[i];
    for (int i = pos; i < arr.length; i++) r[i + ins.length] = arr[i];
    return r;
}
```
